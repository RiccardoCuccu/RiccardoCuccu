## About me

I'm **Riccardo**, a **Digital Design Engineer at Qualcomm** based in **Cork, Ireland**, with an M.Sc. in Electronic Engineering (Embedded Systems) from **Politecnico di Torino**.

Outside of work, I'm studying **the chips that run AI** on my own time: how accelerators are built and what a hardware engineer needs to learn to design them. I share what I learn as I go.

Currently I'm:

- 🧠 Building **[HardwareifAI](https://github.com/RiccardoCuccu/HardwareifAI)**, a personal side project: an open-source curriculum for AI-accelerator hardware design
- 🤖 Using **AI professionally and smartly**: agents, workflow automation and an AI-maintained personal knowledge base that does the tedious work for me
- 🐍 Automating everyday tasks with **Python** and **n8n**
